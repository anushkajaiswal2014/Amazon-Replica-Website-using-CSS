# Amazon Replics Website using CSS

A simple Amazon-style homepage replica built with HTML and CSS.

## Features

- Amazon-like navigation bar
- Search bar layout
- Hero banner section
- Product shopping cards
- Multi-column footer
- Amazon-style header and footer logo

## Files

- `index.html` - page structure
- `style.css` - page styling
- Image files - logo, hero image, and product card images

## How to Run

Open `index.html` in your browser.
